# Freeoguessr

A self-hosted GeoGuessr-style game for playing with friends or solo. Host a
room, share the 5-character code, and guess where in the world each Street
View panorama is. "Play Solo" makes a private room just for you.

Rules (v1): 5 rounds by default, 2 minutes each, worldwide or filtered to a
country or continent. Space locks in your guess. As soon as one player guesses,
everyone else has 10 seconds left. Scoring follows GeoGuessr's curve: up to
5,000 points per round, falling off exponentially with distance.

Two scoring modes, picked in the lobby:

- **Distance (classic)** — scored by distance to the exact spot.
- **Country first** — any guess inside the right country scores 5,000;
  otherwise the same curve applies to the distance from the guess to that
  country's nearest border. (Single-country maps always use classic.)

## Setup

1. Create a Supabase project and run every file in `supabase/migrations/`
   against it, in order (SQL editor or `supabase db push`).
2. Create a Google Cloud project with billing enabled, and enable the
   **Maps JavaScript API** and the **Street View Static API**.
   - Make two API keys: a browser key (Maps JavaScript API only, restricted
     to your domains) and a server key (Street View Static API only).
   - Under *APIs & Services → Quotas*, put a hard daily cap on
     "Dynamic Street View" and "Dynamic Maps" loads so a bug can never run
     up a bill. Google gives 5,000 Street View and 10,000 map loads free per
     month.
3. Copy `.env.local.example` to `.env.local` and fill it in. For Supabase, use the **publishable** and **secret** keys from
   *Project Settings → API Keys* (not the legacy anon/service_role keys).
4. `npm install`
5. `npm run dev`

## Locations

`src/lib/locations.json` is a pool of official Street View locations, each
tagged with its country and continent; `src/lib/regions.json` lists the
countries and continents the lobby can filter by. Both are generated by
`npm run gen:locations`, which samples points inside each country's borders
(Natural Earth boundaries, downloaded on first run) and keeps the ones with
official Google coverage. It only uses free metadata lookups.

Each country gets SCALE × √(area) locations (clamped to 40–600), so
mid-sized countries are playable on their own and the World pool is
balanced like GeoGuessr's official map.

To regenerate a few countries without touching the rest:
`npm run gen:locations -- --only US,FR`

Country-first scoring uses `src/lib/borders.json` (country outlines,
server only) and `src/lib/country-names.json`, built from the same Natural
Earth data by `npm run gen:borders`.

Like GeoGuessr, scoring scales with the map: a filtered game scores against
the distance between that region's two furthest locations instead of the
World map's 14,917 km.

## Cost notes

Google bills Street View per `StreetViewPanorama` created, not per step a
player takes, and the map per `Map` created. The game creates one of each
per player and reuses them across rounds, so a game should cost about one
Street View load and one map load per player. Check the usage graphs in
Cloud Console after your first game to confirm.

## Scripts

- `npm run dev` — local dev server
- `npm run test` — unit tests (vitest)
- `npm run lint` — eslint
- `npm run build` — production build
- `npm run gen:locations` — regenerate the location pool and region list
- `npm run gen:borders` — regenerate country outlines and names
